# Repository Guidelines
Defer to `README.md` for build, work tracking, and coding conventions.

## Local Reminder
- Read `README.md` before making changes.
- Always check the MCPs before starting work.
- Use `TODO.md` for work tracking and reconciliation items.
- Prioritize full functionality in addition to compilability, not compilability instead of full functionality.
- Do not add compile-only stubs as a substitute for porting functionality; missing classes should be fully ported unless the user explicitly approves temporary stubs.
